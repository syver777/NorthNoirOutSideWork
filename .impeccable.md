## Design Context

### Users

Solo YouTube creators and small content teams who want to produce long-form video content without hiring writers, voiceover artists, or video editors. They range from budget-conscious creators looking for the cheapest all-in-one solution (scripts + images + TTS audio → complete video) to those willing to use premium AI video models for higher-quality results. The core value proposition: the best and cheapest option for high-quality YouTube videos, all in one platform.

### Brand Personality

**3-word personality:** Cinematic, Bold, Premium — with a deliberate hint of Simplicity.

**Voice & tone:** Classy, professional, quietly confident. The brand doesn't shout — it commands attention through restraint and quality. Think the difference between a neon billboard and a film title card.

**Emotional goals:** Dark cinematic confidence. Users should feel like they're using a serious, professional tool — not a toy or a generic SaaS product. The interface should evoke the feeling of a high-end production studio, not a template builder.

**Brand name meaning:** "North Noir" — directional + cinematic darkness. The red book logo ties to storytelling/scripts. The palette (red on black) deliberately echoes YouTube's own identity.

### Aesthetic Direction

**Theme:** Dark cinematic — exclusively dark mode. Deep grays and blacks as the canvas, red as the primary accent (matching YouTube's visual language), with radiant accent colors (blues, ambers, teals) introduced sparingly for variety and visual interest in gradients and glows.

**Typography:**

- Headings: Cormorant Garamond (elegant, high-contrast serif — literary/cinematic feel)
- Body: DM Sans (clean, geometric sans — slightly more refined than system defaults)
- Brand wordmark: font-display with tracking-wide for the "North Noir" text

**Color system:**

- Primary palette: Red (#dc2626) + Near-black (#030712 primary canvas, #111827 secondary surfaces, #1f2937 tertiary/elevated)
- Accent text: #ef4444 (links, highlights)
- Border accent: #991b1b (nav, footer borders — subtle red tint)
- Secondary accents: Radiant colors (blues, ambers, teals) used in gradients, glows, and feature differentiation — never as primary UI chrome
- Text: White with opacity variants (100%, 70%, 50%) for hierarchy

**Motion & animation:**

- **Preloader:** Full-screen cinematic entrance on first visit per session (uses `sessionStorage`). A red book video (800×800, `public/bok_reading_red_800.webm` / `.mp4`) plays small and centered on pure black (#000000) for 3 seconds. The video then freezes, fades out quickly (0.8s), and zooms in dramatically (`scale(14)`, 4s) while a circular iris wipe expands slowly from center (5.5s), revealing the landing page beneath. Hero text begins animating in ~1.5s into the zoom — appearing through the opening circle rather than waiting for full completion. The near-black landing page (#030712) blends seamlessly with the preloader's pure black. Navigation slides down from above (0.8s) with glass transparency (`bg-black/30 backdrop-blur-xl`). Respects `prefers-reduced-motion` (skips preloader entirely).
- **Scroll-progress red line:** A glowing red SVG path runs vertically down the page, progressively lighting up as the user scrolls. The line has a gradient glow (dark red → bright red → fading) with a small radiant dot/point that tracks the scroll position along the path. The line connects all major sections, acting as a visual thread through the entire landing page. Implementation reference: `ExampleDesign/Paths&ControlPoints/` (GSAP MotionPathPlugin + ScrollTrigger for path-following and progressive reveal).
- **Pipeline data-flow lines:** From the three pipeline feature sections ("Script & Story", "Voice & Audio", "Images & Video"), red data-flow lines branch out and converge downward into a unified "Completed Video" section. These lines animate with flowing particle/dot effects along the paths as the user scrolls into view — visualizing how three inputs merge into one output. Use SVG paths with GSAP stroke-dashoffset animation and small glowing dots traveling along the curves.
- **Section reveals:** Elements fade/slide into view as the scroll-progress line reaches them — tied to the red line's position, not independent scroll triggers. Staggered entrance timing with cinematic weight.
- Landing page: Cinematic entrance animations — elements should "pop" into view with purpose and weight, not bounce or slide generically
- Pixel-canvas: Subtle interactive hover effects on cards and interactive elements
- Respect `prefers-reduced-motion` (already implemented)

**Landing page structure (conceptual order):**

1. **Preloader** — Red book page-flip animation with percentage counter (0–100%), cinematic reveal on completion
2. **Hero** — Cinematic entrance, core value prop, CTA
3. **Live stats bar** — Real-time user count (from Supabase `public.profiles` row count) + total videos created estimate, displayed as bold animated counters
4. **How It Works intro video** — Embedded video walkthrough showing the platform in action (dynamic player, cinematic framing)
5. **Pipeline feature sections** — "Script & Story", "Voice & Audio", "Images & Video" — each with the scroll-progress red line connecting them
6. **Pipeline convergence** — Red data-flow lines from the three sections above merge into a "Completed Video" result section
7. **Interactive prompt demos** — For each visual style: a prompt input box appears, user types a story prompt, loading animation plays, then an example output video is shown. One demo per style: (a) Image Generation style, (b) Text-to-Video style, (c) Image-to-Video style
8. **Pricing comparison** — Show the cost breakdown for creating a 1-hour video with each visual style, emphasizing North Noir as the cheapest option
9. **Example channels** — Social proof with the card deck layout
10. **Features, FAQ, Why Choose sections**

**Anti-references (explicitly avoid):**

- Canva-bright aesthetics — no pastel palettes, no playful rounded everything
- Cluttered layouts — no information overload, no walls of cards
- Standard/generic SaaS patterns — nothing should look like a template. Every visible element should feel custom to North Noir
- Generic AI aesthetic — no cyan-on-dark, no purple-to-blue gradient clichés, no glassmorphism-everywhere

**References (aligned with):**

- Film title sequences (typography, pacing, dramatic reveals)
- YouTube's own dark mode (red accent on dark surface)
- Premium production tools (DaVinci Resolve, professional editing suites)

### Design Principles

1. **Everything custom, nothing standard.** Every visible element should feel intentionally designed for North Noir. No default component patterns, no template aesthetics. If it looks like it could belong to any SaaS product, redesign it.

2. **Cinematic confidence over flashy spectacle.** Motion and visuals should feel like a film — deliberate, weighted, purposeful. Animations enter with dramatic timing, not bounce effects. The UI commands attention through restraint, not noise.

3. **Dark canvas, radiant accents.** The dark background is the foundation. Color is used sparingly and strategically — red for primary actions and brand identity, radiant accents (blues, ambers) for depth and variety in gradients and glows. Never let accents compete with red.

4. **Simple but never basic.** Reduce visual clutter aggressively, but every remaining element should have craft and polish. Simplicity is the goal, but genericness is the enemy. Clean layouts with rich, intentional details.

5. **Show the value, don't explain it.** The landing page should demonstrate what North Noir does through visual storytelling (the pipeline visualization, example results, cinematic flow) rather than walls of explanatory text. Let the interface speak.
