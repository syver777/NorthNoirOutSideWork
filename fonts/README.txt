Subtitle fonts for SSAIVidGen2.py
==================================

All 10 presets are now bundled — no system font dependency.

Licenses:

  Lobster, Bangers                                            : SIL Open Font License 1.1
  Permanent Marker                                            : Apache License 2.0

Variable fonts:
  Montserrat-VF.ttf  covers Thin..Black weights (used for "Montserrat" and "Montserrat Black")
  Oswald-VF.ttf      covers ExtraLight..Bold weights (used for "Oswald" and "Oswald Bold")

ffmpeg's libass picks these up via fontsdir=fonts (auto-detected by burn_subtitles).
